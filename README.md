# פורטל הכנה למבחן — ניהול ועיצוב בסיסי נתונים (3963)

פורטל למידה אינטראקטיבי בעברית להכנה למבחן בקורס **ניהול ועיצוב בסיסי נתונים**.

## מה יש בפורטל
- 📚 **סיכומי נושאים** — ERD, קרדינליות, המרה ל-DSD, מפתחות, נרמול (1NF–3NF), ו-SQL מלא.
- 🎴 **כרטיסיות זיכרון** — 18 מושגי מפתח.
- ❓ **בוחן אמריקאי** — 15 שאלות עם משוב והסבר מיידי.
- 💻 **מגרש תרגול SQL** — מנוע SQLite חי בדפדפן עם בדיקה אוטומטית מול הפתרון.
- 📝 **סימולציית מבחן** — מבחן מלא (75+25=100 נק') עם טיימר וציון.

## הפעלה
פותחים את `index.html` בדפדפן (לחיצה כפולה).
מסך "תרגול SQL" טוען מנוע מ-CDN ולכן דורש חיבור אינטרנט; שאר המסכים עובדים גם ללא רשת.

## מבנה הקבצים
```
index.html          — הדף הראשי
css/styles.css      — עיצוב
js/content.js       — כל תוכן הקורס (סיכומים, שאלות, נתוני SQL)
js/app.js           — הלוגיקה
```

התוכן מבוסס על חומרי הקורס (מצגות, מבחן לדוגמה ותבניות SQL).
